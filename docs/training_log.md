# icefall Zipformer2 训练日志与结果分析

## 项目概述

基于 WenetSpeech M+S 子集训练中文 ASR 模型，使用 icefall 官方 Zipformer2 架构 + k2 pruned RNN-T / CTC 联合损失。

## 模型配置

| 项目 | 配置 |
|------|------|
| Encoder | icefall Zipformer2, 2-stack (384d, 512d) |
| Encoder params | 61.8M |
| Predictor | Stateless (embedding + Conv1d), 512d |
| Joiner | Linear, hidden=512 |
| CTC head | Linear(512, 6000) |
| **Total params** | **79.6M** |
| Tokenizer | SentencePiece unigram, vocab=6000 |
| Data | WenetSpeech M+S subset, ~1.5M utterances |

## 训练超参数

| 参数 | 值 |
|------|-----|
| Optimizer | AdamW |
| Peak LR | 1.5e-4 |
| Betas | (0.9, 0.98) |
| Weight decay | 0.01 |
| Grad clip | max_norm=1.0 |
| Warmup | 8000 steps |
| Schedule | Cosine decay → 5e-6 |
| Precision | float32 |
| Batch | max_duration=120s/batch |
| Steps/epoch | ~30,005 |
| Epochs | 50 |

icefall Zipformer2 相比自定义版本：
- CER 降低 **34.8 个百分点**（58.5% → 23.7%）
- Loss 降低一半以上
- 训练全程稳定，无发散

## 错误分析（Epoch 36）

当前剩余错误的主要类型：

| 错误类型 | 示例 | 占比 |
|---------|------|------|
| 同音字混淆 | 美静→北京, 樱→英, 吉→鸡 | ~40% |
| 句首/句尾缺失 | "让女孩" 丢失 "让", "喝吧" 丢失 | ~25% |
| 近音替换 | 湿→尸, 划→花 | ~20% |
| 语义错误 | 戏院→医院, 考虑→卡 | ~15% |

## 后续优化方向

1. **继续训练** — 当前 Epoch 37，loss 仍在下降，跑完 50 epoch 预期 CER 可到 18-20%
2. **语言模型 Rescore** — 加入 n-gram 或 neural LM 对 beam search 结果做 rescore，可解决大部分同音字混淆
3. **RNN-T 解码** — 当前只用了 CTC greedy，RNN-T beam search 解码效果应更好
4. **数据扩增** — 加入 SpecAugment、速度扰动、噪声混合
5. **更大数据** — 当前只用 M+S (10%)，加入经过过滤的 L 子集可增加数据量
6. **Averaged model** — 对最后 5-10 个 epoch 的 checkpoint 做参数平均，通常可降 1-2% CER
